# Python 舒尔特方格游戏

这是一个基于 Python 标准库 Tkinter 实现的舒尔特方格小游戏，支持 `3 x 3` 到 `10 x 10` 的方格，也就是最大支持 `1` 到 `100`。

## 玩法

1. 选择难度。
2. 点击“开始游戏”。
3. 按顺序从 `1` 一直点击到当前难度的最大数字。
4. 完成后会显示本轮用时，并记录当前难度下的最佳成绩。

## 运行

确保本机安装了 Python 3，然后在项目目录执行：

```bash
python main.py
```

Windows 下如果 `python` 不可用，也可以尝试：

```bash
py main.py
```

## 特性

- 无第三方依赖
- 错误点击提示
- 实时计时
- 支持重新洗牌

这是一个基于 Python 标准库 `tkinter` 实现的数字舒尔特方格小游戏，支持从 `9` 到 `100` 的多种数字规模挑战。

## 运行方式

确保本机安装了 Python 3，然后在项目目录执行：

```powershell
python main.py
```

## 玩法说明

- 点击“开始新游戏”随机生成方格。
- 按照 `1`、`2`、`3` 的顺序依次点击数字。
- 选错数字会有提示，但游戏不会结束。
- 完成当前规模后会显示用时，并记录当前运行期间的最佳成绩。
